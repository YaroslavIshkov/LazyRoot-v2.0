Здравствуйте, сегодня я бы хотел представить вам свой новый алгоритм упаковки данных, который работает по принципу ленивой змейки, храня данные в виде блоков по 128 - 512 бит по матрицам.

Библиотеки:
Python 🐍 версии 3.8 и новее
Psutil версии 7.2.2
Numpy версии 2.4.6
PyCryptoDome версии 3.23.0

Установить библиотеки можно одной командой:
pip install -r requirements.txt
